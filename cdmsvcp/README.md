# cdmsvcp — Edit Distance to Full Flat-Foldability at a Single Vertex

Implementation of the **FullRepair** algorithm from:

> Callegaro, S. *"Crease Modifications to Full Flat-Foldability at a Single Vertex:
> Kawasaki and Maekawa Simultaneously."* (2026).

Extends the [cdsvcp](../cdsvcp/) package (which handles the geometry-only Kawasaki
distance) to the labelled setting where both the **Kawasaki–Justin** condition
(alternating angle sums equal π) and the **Maekawa** condition (|M − V| = 2)
must hold simultaneously.

---

## Overview

A **labelled single-vertex crease pattern** (LSVCP) is a pair (C, μ) where:

- C is an SVCP — a cyclic sequence of positive sector angles summing to 2π.
- μ : {1, …, m} → {M, V} is a mountain/valley assignment.

It is *fully flat-foldable* if and only if:

1. m is even
2. **Kawasaki deficit** κ(C) = S_odd − π = 0
3. **Maekawa deficit** ν = |M − V| − 2 = 0

Two operations are available:

- **Labelled crease insertion**: split a sector into two; assign a freely chosen
  label (M or V) to the new crease. Changes m by +1 and alters the geometry.
- **Label flip**: toggle an existing crease between M and V. Leaves the angles
  completely unchanged.

### Main theorem (d_MV)

For **even m** (writing ν = |δ| − 2, δ = M − V):

| κ         | ν         | d_MV        |
|-----------|-----------|-------------|
| κ = 0     | ν = 0     | 0           |
| κ = 0     | ν ≠ 0     | \|ν\|/2     |
| κ ≠ 0     | \|ν\| ≤ 2 | 2           |
| κ ≠ 0     | \|ν\| ≥ 4 | \|ν\|/2 + 1 |

For **odd m**: d_MV = max(1, (|δ| − 1) / 2).

## Quick start

```python
from fractions import Fraction
from cdsvcp import SVCP
from cdmsvcp import LSVCP, M, V, edit_distance, repair

# (120°, 80°, 100°, 60°) with labels M M M M
# κ ≠ 0, ν = 2  →  d_MV = 2
C = SVCP((Fraction(2,3), Fraction(4,9), Fraction(5,9), Fraction(1,3)))
lc = LSVCP(C, (M, M, M, M))

print(edit_distance(lc))    # → 2

lc_star, ops = repair(lc)
for op in ops:
    print(op)
# LabelledOp(kind='insert', pos=1, param=..., label='V')
# LabelledOp(kind='insert', pos=2, param=..., label='V')
```

## Command-line interface

Angles are given as fractions of π (1/2 = 90°, sum must equal 2).
Labels follow `--`: M for mountain, V for valley.

```bash
# Already fully flat-foldable:
cdmsvcp 1/2 1/2 1/2 1/2 -- M M M V

# Case B (one flip needed):
cdmsvcp 1/2 1/2 1/2 1/2 -- M M M M

# Case C (two insertions):
cdmsvcp 2/3 4/9 5/9 1/3 -- M M M V --repair

# Case D with verbose output:
cdmsvcp 4/9 1/3 7/18 5/18 1/3 2/9 -- M M M M M M --repair --verbose

# Odd m:
cdmsvcp 2/3 2/3 2/3 -- M M M --repair
```

## Relationship to cdsvcp

`cdmsvcp` depends on and re-uses `cdsvcp`:

- `SVCP`, `insert`, `kawasaki_deficit`, `kawasaki_residual`, `is_flat_foldable`
  are imported from `cdsvcp` and re-exported.
- `two_insert` and `single_insert` from `cdsvcp` are called internally by
  `FullRepair` to find the geometrically correct insertion positions (Cases C, D, E).
  The label choice (M/V) is then applied on top.

No changes to `cdsvcp` are required.
